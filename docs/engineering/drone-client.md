# Native Drone Client

## Overview

The Native Drone Client is the autonomous flight controller for the Falcon platform.

Developed using modern C++20, the Drone Client maintains aircraft state, processes flight commands, executes guidance algorithms, and continuously publishes telemetry to the Falcon messaging infrastructure.

Unlike browser-based simulators, the Drone Client represents the aircraft itself and is responsible for autonomous flight behavior and real-time state management.

---

# Responsibilities

The Drone Client is responsible for:

• Maintaining aircraft state

• Processing flight commands

• Executing autonomous missions

• Publishing telemetry

• Reporting aircraft health

• Managing flight modes

• Maintaining MQTT connectivity

# Command Processing

The Drone Client subscribes to aircraft command topics and executes validated commands.

Current commands include:

• START_MISSION

• PAUSE_MISSION

• RESUME_MISSION

• HOVER

• RETURN_TO_HOME

• LAND

• SET_ALTITUDE

• SET_HEADING

Each command generates an acknowledgement indicating:

• Accepted

• Rejected

• Failed

The command acknowledgement is returned through MQTT and displayed within the Drone Console.

• Voltage

• Temperature

---

# MQTT Integration

The Drone Client communicates exclusively through MQTT.

Published Topics

• Aircraft Status

• Telemetry

• Command Status

Subscribed Topics

• Aircraft Commands

This messaging model decouples the aircraft from the browser interface and allows multiple consumers to observe aircraft activity simultaneously.
