# User Guide

## Overview

This guide explains how to operate the Falcon platform.

It covers the Drone Console, telemetry monitoring, aircraft control, and system status.

---

# Dashboard

The Drone Console displays:

• Connection status

• Flight mode

• Aircraft position

• Battery status

• Heading

• Speed

• Activity history

---

# Connection Status

Possible values include:

Disconnected

Connecting

Connected

Error

Ensure the gateway is connected before attempting to control an aircraft.

---

# Flight Commands

Available commands include:

• Start Mission

• Pause Mission

• Resume Mission

• Hover

• Return Home

• Land

Each command is validated before being transmitted to the aircraft.

---

# Telemetry

Live telemetry includes:

• Latitude

• Longitude

• Altitude

• Heading

• Speed

• Battery

• Temperature

• GPS status

Telemetry updates automatically.

---

# Activity History

The Activity panel records:

• Commands

• Status changes

• Connection events

• Operational messages

Use the activity log when troubleshooting.

---

# Observation Lounge

Observation Lounge provides operational visibility into platform services.

It displays:

• Service health

• Incidents

• Performance

• Fleet status

---

# Best Practices

Always verify:

• Aircraft connection

• Flight mode

• Battery level

• GPS availability

before issuing commands.

---

# Summary

The Drone Console provides a centralized interface for monitoring and operating Falcon aircraft.
