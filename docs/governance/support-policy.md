# Support Policy

## Overview

This document defines the support lifecycle for Falcon software and documentation.

Support levels help communicate maintenance expectations for each platform component.

---

# Support Levels

## Active Development

Features are actively evolving.

New functionality may be introduced.

Breaking changes are possible.

---

## Supported

The component receives:

• Bug fixes

• Security updates

• Documentation updates

• Compatibility improvements

---

## Maintenance

The component remains operational but receives only critical fixes.

No new features are planned.

---

## Deprecated

The component is scheduled for removal.

Migration guidance will be provided when applicable.

---

## End of Life

The component is no longer maintained.

Support is discontinued.

# Reporting Issues

Issues should include:

• Component

# Summary

The Falcon support policy establishes clear maintenance expectations while helping users understand the lifecycle of platform components.
